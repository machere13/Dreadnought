Выигрыша по токенам нет: Dreadnought дороже на 1,34% по основной метрике и на 1,91% по всем входным и выходным. Время практически одинаковое. Нельзя приписать всю разницу с v7 оптимизации: отличаются независимые генерации и кеширование.

Обе сборки и восемь общих функциональных проверок прошли без исправлений. Код библиотечного варианта использует шесть публичных компонентов, CSS Modules, без внутренних селекторов, !important и переопределений компонентных токенов. До признания выигрыша требуется визуальная проверка; в этом неудачном прогоне она не проводилась.

Bootstrap действительно вызывает MCP; он не содержит решения экрана. Компактное представление сохранило все типы, обязательность свойств и ветви контрактов (проверено compactContext.test.mjs). Библиотека не менялась.
