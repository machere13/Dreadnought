# Чистый прогон v8

3 октября 2026. Задание, замороженные пакеты без CollectionPage, одинаковые функциональные проверки и метрики — как в [v7](../token-comparison-v7/PROTOCOL.md). Новые независимые агенты без истории и новые пустые src. Сначала запускается React/CSS, затем Dreadnought (обратный порядок v7). v7 не скрывается: 38396 против 20355 входных без кеша + выходных, проигрыш библиотеки.

Изменение эксперимента: один начальный bootstrap-вызов у каждого агента читает полный ponytail и настройки проекта. Для библиотечного варианта этот же вызов читает скилл и получает публичный API через MCP, затем убирает дублирующие поля JSON, сохраняя примеры, типы, обязательность свойств и ветви контрактов. Это автоматическое форматирование ответа, не генерация экрана ведущим. Полный ответ остаётся доступен через MCP get. Входные токены полученного текста входят в расход агента.

Оба агента по-прежнему самостоятельно пишут весь экран и выполняют сборку. Библиотечный агент не получает ни кода бизнес-логики, ни готовой композиции. Библиотека и её API не меняются. Визуальные и функциональные требования не ослабляются. Результат сравнивается с новым React/CSS-агентом, не с наиболее затратным старым прогоном.
