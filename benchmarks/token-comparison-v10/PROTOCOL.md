# Чистый прогон v10

3 октября 2026. Те же задача, пакеты, проверки, модель и метрики, что в v7–v9. Новые агенты без истории и пустые src. Первым запускается React/CSS. Библиотека не изменяется; CollectionPage отсутствует.

После проигрыша v9 (21960 против 17591 по основной метрике) меняется только способ первоначальной выдачи: к примерам добавлены точные значения простых свойств из контрактов (в том числе варианты Button/Badge), а скилл требует запрашивать get только для конкретного отсутствующего свойства, нужного реализации. Уточнено, что класс на готовом Card не должен переопределять его padding и прочий дизайн. Полные API доступны; искусственных запретов на необходимые запросы нет.

Это последовательный поиск способа работы с каталогом. Неудачные попытки сохраняются. При первом выигрыше — ещё один независимый парный повтор того же способа с обратным порядком запуска. Сокращение функций задания или изменения библиотеки запрещены.
