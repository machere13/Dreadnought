# Проверка переноса скилла

Проверена основная реализация `context --format usage`, не benchmark-обёртка. Свежий агент прочитал обновлённый скилл и построил `UsageProbe.tsx` с шестью публичными компонентами, управляемыми Tabs, submit Button и Table.render. Достаточно одного запроса; `get`, `contract`, `search`, запросы токенов не понадобились. Проба прошла строгую типизацию на установленных frozen-пакетах из v12.

Первый запуск tsc не нашёл пакет из корня репозитория — ошибка подготовки проверки. Локальный tsconfig указывает на публичную декларацию уже установленного пакета; компонент и библиотека не изменялись для обхода ошибки. Команда:

```sh
node benchmarks/token-comparison-v12/with-dreadnought/node_modules/typescript/bin/tsc -p benchmarks/catalog-promotion/tsconfig.json
```

На вопрос о дефекте mobile Tabs агент выбрал воспроизведение/исправление библиотеки с разрешения, а не внутренний CSS-селектор или подмену на layer 2. Это проверка применения инструкции, не новый замер экономии и не визуальный аудит компонента.

Предшествующие неудачи инструкции: v9 — лишние запросы после examples-only и переопределение Card.padding; v10 — ошибочный сокращённый Button.type и исправление типов columns после первой сборки. V11/v12 проверили исправленный подход на полном экране. При переносе дополнительно отмечена неполнота API и исключены свойства со сложными типами хотя бы в одной библиотечной ветви; полные контракты остаются в get.

Старые bootstrap/тесты v8–v12 теперь явно запрашивают `format: contract` для своего экспериментального преобразователя, поскольку основной context по умолчанию возвращает usage. Реализации экранов и сохранённые измерения не менялись.
