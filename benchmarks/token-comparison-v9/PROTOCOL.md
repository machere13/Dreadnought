# Чистый прогон v9

3 октября 2026. Условия и функциональное задание из [v7](../token-comparison-v7/PROTOCOL.md) сохранены. Новые агенты без истории, пустые src, прежние архивы библиотеки без CollectionPage. Порядок запуска: Dreadnought, затем React/CSS. Нельзя менять пакеты или читать исходники библиотеки.

v8 проиграл по основной метрике: 17374 против 17144. Его результаты сохраняются. Новый эксперимент оставляет один bootstrap-вызов, но даёт режим примеров: совместимость, публичные импорты и по одному работающему примеру на компонент. Он явно не объявляется полным API; недостающие сведения можно получить обычным MCP get. Типы в примерах проверяются против опубликованного пакета. В экспериментальном снимке каталога добавлены обычный текстовый Input и вариант Table с существующими columns/dataSource, render, pagination и locale. Никакого кода экрана, фильтрации, счётчиков или формы эти примеры не содержат.

Основная метрика — вход без кеша + выход; также весь вход + выход, время, инструменты. Подготовка ведущим исключается, ответы инструмента и исправления агента включаются. Все неудачи публикуются. При выигрыше выполняется ещё один независимый повтор того же способа, чтобы проверить, не оказался ли результат единичным удачным запуском.
