# Сравнение расхода токенов: один экран

**Этот прогон не проверяет предусмотренный AI-сценарий Dreadnought.** Агенту не были подключены Skill, MCP и машиночитаемый каталог. Ему пришлось самостоятельно искать API в исходниках и документации. Поэтому цифры ниже характеризуют только подключение библиотеки без второго AI-контура; делать по ним вывод об экономии токенов всей архитектуры нельзя.

Дата: 2 октября 2026. Два независимых агента на `gpt-6-sol`, без истории переписки, получили одинаковое ТЗ на экран «Командная доска» и применяли `ponytail`. Различие: один использовал Dreadnought, другой — только React и CSS.

| Показатель | С Dreadnought | Без Dreadnought |
| --- | ---: | ---: |
| Входные токены, всего | 4 159 490 | 1 889 578 |
| Из них кешированные | 4 049 024 | 1 854 080 |
| Входные без кеша | 110 466 | 35 498 |
| Выходные токены | 14 552 | 10 129 |
| Входные без кеша + выходные | **125 018** | **45 627** |
| Все токены, включая кеш | 4 174 042 | 1 899 707 |
| Собственный TSX + CSS, байт | 10 035 | 11 512 |
| JS в production build, gzip | 84,29 КБ | 71,07 КБ |
| CSS в production build, gzip | 8,13 КБ | 1,68 КБ |
| Production build | прошёл | прошёл |

По метрике «вход без кеша + выход» вариант с Dreadnought потратил **в 2,74 раза больше токенов**. При этом исходники экрана на 12,8% меньше по объёму в байтах. Физические строки CSS не сопоставимы: во втором варианте весь CSS записан в одну строку.

Агент с Dreadnought использовал `Button`, `Input`, `Card`, `Badge`, `Tabs`, `Table` и проверил фильтр, поиск, добавление задачи, счётчик и ширину 390px в браузере. Вариант без библиотеки прошёл сборку, но браузер агента заблокировал localhost; его интерактивность подтверждена только просмотром кода, не кликом.

Это **один некорректно поставленный для нашей цели end-to-end прогон**. В токены входят ручное изучение API и установка пакетов. У варианта с библиотекой сначала не прошла установка через npm; рабочим оказался offline pnpm с локальными overrides. Агенту была дана подсказка об этом во время прогона. Вариант без библиотеки потратил часть работы на безуспешную браузерную проверку. Для проверки всей архитектуры нужен новый прогон: одинаково подготовленные окружения, агенту с Dreadnought доступен Skill и запросы к каталогу через MCP, а самостоятельный поиск API не требуется.

Источник чисел — последние `token_usage_record.thread_token_usage` двух журналов агентов, а не оценка по объёму кода. Кешированные входные токены учтены отдельно; «вход без кеша + выход» не является денежной стоимостью API.
