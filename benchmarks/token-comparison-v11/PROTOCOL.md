# Чистый прогон v11

3 октября 2026. Те же задача, frozen-пакеты без CollectionPage, модель, критерии, метрики и восемь проверок v10. Два новых агента без истории, пустые src. Первым запускается Dreadnought; при выигрыше повторяем тот же способ с обратным порядком. Все неудачи сохраняем. Исходники библиотеки не меняем.

Изменение v10: сокращение больше не выдаёт одиночное undefined как полный тип свойства. Скилл поясняет стандартный Button.type и сохранение литералов вынесенного массива Table columns. Это общие указания по API, без кода экрана и предметной логики. Примеры остальных компонентов не меняются.

Основная метрика: некешированный вход + выход. Также обязательно публикуются все входные + выходные, кеш, количество ответов, исправления и время. Подготовка окружения и анализ экспериментатора не входят в время/токены агентов; это не общая стоимость разработки библиотеки. Кеш может различаться; результаты нельзя выдавать за универсальную оценку.
