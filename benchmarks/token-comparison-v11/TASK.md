# Одинаковое задание для v11 и подтверждающего v12

Экран «Командная доска»: тёмный графитовый фон, светлый текст, сдержанные границы. Заголовок и кнопка «Новая задача», левая навигация при 1280px. При 360px горизонтально прокручиваться может таблица, но не вся страница.

- Три карточки «Всего», «В работе», «Готово» считают все задачи независимо от фильтра.
- Поле «Поиск задач» ищет название и исполнителя без учёта регистра, совместно с вкладками «Все», «К выполнению», «В работе», «Готово».
- Таблица: «Задача», «Исполнитель», «Статус», «Приоритет»; статусы — бейджи.
- Начальные строки: 1 / Собрать требования / Анна / В работе / Высокий; 2 / Проверить макет / Борис / К выполнению / Средний; 3 / Подготовить релиз / Вера / Готово / Низкий.
- Нативный dialog с доступным именем. Обязательные «Название задачи», «Исполнитель», не принимающие одни пробелы; select «Статус» и «Приоритет»; «Создать задачу», «Отмена».
- Создание закрывает диалог, сбрасывает поиск/вкладку, показывает новую строку и обновляет счётчики. Пустой результат: «Задачи не найдены».
- Доступные подписи, клавиатурная навигация вкладок, Escape закрывает диалог. Локальное состояние без сервера, лишних функций и страниц; читаемый минимальный код.

Оба агента получают полную Ponytail, одинаковые стартовые файлы и инструкции не читать соседние проекты, прежние реализации, отчёты, исходники библиотеки или историю агентов. Менять только собственный src. Собственных агентов не запускать. Зависимости уже установлены. Финальная команда агента — `pnpm run build`, исправления включаются в его расход. Внешние проверки выполняет ведущий.

Отличие: библиотечный агент использует публичные Button, Input, Card, Badge, Tabs, Table из `@dreadnought/ui/react`, CSS Modules для окружающей компоновки и нативный HTML для отсутствующих примитивов. Не переопределяет внутренние стили, токены или классы. Вариант без библиотеки использует React, HTML и собственный CSS.

Первый вызов агента: `node <run>/bootstrap.mjs with-dreadnought Button,Input,Card,Badge,Tabs,Table` либо `node <run>/bootstrap.mjs without-dreadnought`. Bootstrap печатает полную Ponytail и стартовые файлы, для библиотеки дополнительно SKILL и результат живого MCP-вызова. Дополнительные API доступны через `node <run>/mcp-query.mjs get component=... binding=react-ui section=api property=...`. Контекст новой сессии не наследуется (`fork_turns: none`), модель/effort наследуются одинаковые.

Разделение доступов инструкционное, не отдельная OS-песочница; это ограничение эксперимента. Подготовка, разработка инструментария и внешняя проверка не входят в стоимость генерации экрана. Сравнение не оценивает первоначальную стоимость создания библиотеки.
