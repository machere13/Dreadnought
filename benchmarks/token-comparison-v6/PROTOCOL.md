# Протокол v6 — зафиксирован до запуска агентов

## Общая задача

В двух новых React/TypeScript/Vite-проектах сделать один экран «Командная доска»: тёмный графитовый фон, светлый текст, сдержанные границы, адаптивная шапка с кнопкой новой задачи, боковая навигация, три счётчика, поиск, вкладки, таблица задач из четырёх столбцов, бейджи статусов, модальная форма с обязательными названием и исполнителем и полями статуса/приоритета. Добавление задачи обновляет список и счётчики; поиск и вкладки фильтруют список; при отсутствии совпадений есть пустое состояние. Поля имеют доступные имена. Никакое имя CSS-файла или способ подключения стилей не предписывается.

Одинаковая задача передаётся двум независимым агентам одной модели. Оба читают `ponytail`. Агент с Dreadnought читает актуальный `tools/skills/dreadnought/SKILL.md`, пользуется только публичным API установленной библиотеки и локальным MCP-каталогом. Второй использует React/HTML/CSS без UI-библиотеки. Старые реализации и отчёты обоим недоступны по инструкции. Агенты редактируют только собственные новые проекты.

## Проверка после завершения

Обе реализации должны пройти production build и один общий smoke-тест: исходная задача видна, новая добавляется, поиск показывает пустое состояние.

Для варианта с Dreadnought отдельно проверяются заранее заданные условия корректного применения третьего слоя: используются готовые компоненты; нет `!important`; нет прямого переоформления их внутренних DOM/классов; нет не запрошенной пользователем смены компонентных токенов/палитры; стили приложения — CSS Modules, глобальный CSS допустим только для базового HTML/body reset. Если условие нарушено, расход всё равно публикуется, но прогон отмечается как невалидный для оценки расхода при правильном применении библиотеки.

Основная метрика — входные токены без кеша + выходные токены из журналов независимых агентов. Дополнительно показываются все входные/выходные токены, количество шагов, размер собственного кода и production bundle. Подготовка и независимая проверка не включаются в агентский расход. Один прогон не интерпретируется как статистически надёжный эффект.
