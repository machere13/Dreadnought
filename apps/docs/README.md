# Документация Dreadnought

Статический Astro-сайт. API-таблицы и общие примеры 14 компонентов получаются из проверенного каталога, а пояснения и интерактивные демонстрации остаются в страницах.

## Команды из корня

```sh
pnpm docs
pnpm docs:build
pnpm docs:refresh
```

`docs` сначала строит каталог, данные API, страницы и поисковый корпус, затем запускает Astro dev. `docs:build` выпускает сайт в `apps/docs/dist`. `docs:refresh` обновляет тот же корпус для уже запущенного dev-сервера; после изменения метаданных или руководств выполните команду и перезагрузите страницу. Горячая замена страницы сама по себе не перестраивает поисковый индекс.

Производные файлы не редактируются и не коммитятся: `src/generated/catalog-docs.json`, `public/{catalog,rag-index,knowledge-manifest}.json`, `dist`. Перед проверкой типов на чистом checkout сначала выполните сборку документации, чтобы создать данные API.

## Источники и проверки

`tools/catalog` читает публичные TypeScript-контракты и редакционные `catalog.json` рядом с реализациями. Составные части имеют собственные контракты, отсутствующие слои не выдумываются. Метаданные описывают назначение и проверяемые значения по умолчанию, но не повторяют типы.

`scripts/buildKnowledge.mjs` объединяет каталог с отмеченными `data-knowledge` разделами 18 разрешённых страниц (`src/knowledge/routes.json`). Навигация, планы проекта, API-таблицы и повторные примеры в корпус не включаются. Ссылки и якоря проверяются после сборки. Каталог, индекс и страницы публикуются вместе; загрузчик проверяет версии и идентификатор сборки и не принимает старый индекс.

Поиск сайта и помощника используют один текстовый поиск с русскими и английскими соответствиями. Это не векторная база: сложные перефразировки могут не найти источник. При недостаточном совпадении помощник не запускает генерацию.

## Локальный помощник

Модель `Qwen3-1.7B-q4f16_1-MLC` запускается через зафиксированный WebLLM 0.2.85 в Worker. Только нажатие «Загрузить модель» инициирует загрузку примерно 1 ГБ с Hugging Face/GitHub. Нужны WebGPU и около 2 ГБ свободной памяти GPU. Веса не входят в статический выпуск; браузерный кэш может быть очищен самим браузером.

Вопросы и ответы не отправляются серверу генерации. Генерация запускается отдельно, получает только найденные фрагменты и ограниченный контекст; большие примеры либо включаются целиком, либо пропускаются. Отмена завершает Worker. Источники остаются доступны при ошибке модели, без WebGPU и до загрузки весов.

Ответ отображается как текст, не исполняется. Ссылки строятся только по ID переданных источников. Это ограничивает поддельные ссылки, но **не гарантирует фактическую правильность ответа**: помощник экспериментальный, код следует сверять с источником и TypeScript. Устройство для показа нужно проверять отдельно.

MCP-сервер не является частью сайта. Он сможет читать тот же каталог отдельным потребителем.

## Проверено локально

30 сентября 2026: production-сборка 18 маршрутов, каталог 14 компонентов и 500 поисковых фрагментов; 276 тестов и общая проверка типов прошли. В браузере проверены загрузка модели и повторный запуск с кэшем, настоящий ответ про `Input type="password"`, переход к API по цитате, отмена загрузки/генерации, отказ по запросу `Angular Button` и клавиатурный переход к источникам. На узкой ширине проверен интерфейс помощника.

Отсутствие WebGPU, запоздалые ответы и ошибка движка покрыты тестами с подменным движком. Физическое устройство для презентации, его память, скорость и сетевые ограничения нужно проверить отдельно; эти результаты не гарантируют одинаковую работу на любом GPU.
