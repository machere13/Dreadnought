# Breadcrumb

Показывает путь до текущей страницы. Пункты перед последним могут быть ссылками; последний автоматически получает `aria-current="page"` и остаётся обычным текстом, если `href` не передан.

```tsx
import { Breadcrumb } from '@dreadnought/ui/react';

<Breadcrumb
  items={[
    { label: 'Главная', href: '/' },
    { label: 'Документация', href: '/docs' },
    { label: 'Компоненты' },
  ]}
/>;
```

Компонент использует `nav` с упорядоченным списком. По умолчанию его доступное имя — `Breadcrumb`; для русскоязычной страницы можно передать `aria-label="Навигационная цепочка"`. Список без пунктов ничего не рендерит.

Готовый компонент оформляется токенами `--dreadnought-breadcrumb-*`. Для отдельного экземпляра задайте их через `className`, для темы — в компонентных токенах. Внутренние части доступны через `slotClassNames` (`list`, `item`, `link`, `current`). Разделитель — только визуальный CSS-псевдоэлемент: он не озвучивается скринридером.

Если нужно своё оформление, используйте `BreadcrumbAdapter` из `@dreadnought/react/unstyled`: он предоставляет ту же семантику без стилей темы.
