# Menu

Переиспользуемый список действий или выбора. Menu отвечает за пункты, доступность, фокус и клавиатурную навигацию. Его можно показывать самостоятельно или внутри всплывающего окна: Tabs уже использует это меню, будущий Dropdown сможет использовать его без копирования пунктов и клавиатурной логики.

```tsx
import { Menu } from '@dreadnought/ui/react';

<Menu
  aria-label="Действия"
  items={[
    { value: 'copy', label: 'Копировать' },
    { value: 'delete', label: 'Удалить', disabled: true },
  ]}
  onAction={(value) => console.log(value)}
/>;
```

Каждый пункт имеет непустой уникальный `value`, `label` типа ReactNode и необязательные `disabled` и `ariaLabel`. В подпись можно включить Icon или Mark; не вкладывайте интерактивные элементы в кнопку пункта. `onAction` получает значение выбранного доступного пункта.

Без `selectedValue` пункты имеют роль `menuitem` и выполняют действия. С `selectedValue` они имеют роль `menuitemradio` и показывают выбранный пункт; обновление значения остаётся у владельца. Это позволяет использовать одно Menu и для команд Dropdown, и для выбора вкладки Tabs.

Стрелки вверх/вниз циклически перемещают фокус, пропуская отключённые пункты. Home/End переходят к первому/последнему доступному пункту. Enter/Space выполняют действие. В Tab-порядке находится один доступный пункт. Корневой `aria-label` или `aria-labelledby` задаёт имя меню, `ref` относится к элементу `role="menu"`.

`className` меняет корень, `slotProps.item` задаёт свойства и класс кнопок пунктов. Оформление настраивается через `--dreadnought-menu-*`; меню внутри Tabs использует эти же токены. Токены `--dreadnought-tabs-*` относятся к самой полосе вкладок.

Во втором слое доступен `MenuAdapter` из `@dreadnought/react/unstyled`. Общий переход между доступными пунктами — `getNextEnabledValue` из `@dreadnought/core`; существующий `getNextTabValue` использует это же правило. Оформленный Menu, CSS Module и токены находятся в третьем слое.

Открытие, закрытие по Escape/клику снаружи, позиционирование и возврат фокуса на триггер принадлежат владельцу всплывающего окна. Сейчас это `TabsOverflowMenu`; при реализации Dropdown это поведение следует перенести в его адаптер и переиспользовать в Tabs. Не добавляем открытие и позиционирование в список Menu.
