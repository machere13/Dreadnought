# Badge

Пассивная метка для короткого текста, числа или иконки. Не является кнопкой и не включает живые уведомления.

```tsx
import { Badge, Button } from '@dreadnought/ui/react';

<Badge icon={<StarIcon />}>Beta</Badge>;
<Badge appearance="outline">New</Badge>;
<Badge target={<Button aria-label="Уведомления, 3 новых">Уведомления</Button>}>3</Badge>;
```

`children` всегда задаёт содержимое самой метки. `target` размещает её поверх переданного элемента; этот элемент не клонируется и сохраняет собственные обработчики и фокус. `icon` добавляет графику, а `iconPosition="start" | "end"` задаёт её порядок относительно текста. `appearance="solid" | "outline"` выбирает внешний вид; по умолчанию используется `solid`. Стандартные атрибуты `<span>`, `className` и `ref` передаются корневому элементу.

Число `0` отображается; автоматического скрытия или сокращения больших чисел нет. В режиме с `target` визуальная метка скрыта от дерева доступности. Если её значение важно, включите его в доступное имя целевого элемента или дайте рядом эквивалентный текст. Иконка декоративная: важный смысл передавайте текстом. Компонент не добавляет `aria-live` и не делает обёртку фокусируемой.

`BadgeAdapter` доступен через `@dreadnought/react/unstyled` для собственной темы. Готовый `Badge` использует CSS Module и стандартные токены `--dreadnought-badge-*`; свойства можно изменить на контейнере или у одного экземпляра через `className` без `!important`.
