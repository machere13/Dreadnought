# Общие действия

Действия экспортируются из `@dreadnought/core`. Они не зависят от React и могут вызываться из любого веб-компонента.

## `copy(text)`

Копирует строку в буфер обмена. Возвращает промис браузерного Clipboard API: `await copy(text)` завершается после записи. Если браузер не разрешил доступ к буферу, ошибка передаётся вызывающему коду. Для Clipboard API нужен защищённый контекст (обычно HTTPS или localhost).

## `download(blob, filename)`

Запускает скачивание `Blob` с указанным именем через временную ссылку. Ссылка удаляется после клика, её URL освобождается с задержкой. Функция не отслеживает завершение загрузки и не загружает файл из сети; эти задачи остаются вызывающему коду.
