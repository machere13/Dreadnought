**Goal:** Добавить Toolbar, на котором можно собрать панель из библиотечных и собственных контролов, переиспользуя независимые правила core.

**Architecture:** Core вычисляет семантику и единственную точку входа Tab. React-адаптер хранит явно зарегистрированные узлы, управляет фокусом и событиями; UI добавляет только оформление. Режим native не вмешивается в клавиатуру полей и объявляет обычную группу.

**Spec:** `docs/superpowers/specs/2026-10-05-toolbar-design.md` — прочитать полностью перед исполнением.
