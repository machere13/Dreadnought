# Badge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить самостоятельную метку и метку поверх элемента в публичные неоформленный и оформленный React API Dreadnought.

**Architecture:** `BadgeAdapter` строит неинтерактивную структуру без CSS. `Badge` применяет общую карту классов; CSS Module и стандартная тема задают оба варианта оформления. В `core` нет новой реализации, пока не появится вычисляемое поведение.

**Tech Stack:** TypeScript, React 19, CSS Modules, CSS custom properties, Vitest, Testing Library, pnpm.

**Spec:** [2026-09-26-badge-design.md](../specs/2026-09-26-badge-design.md)

## Global Constraints

- Компонент хранится под `DataDisplay/Badge` во втором и третьем слоях, теме и зеркальных тестах; публичные импорты остаются через существующие entrypoints.
- `children` всегда содержимое метки; `target` — необязательный React-элемент, расположенный под ней.
- `appearance` принимает `solid | outline`, `iconPosition` принимает `start | end`; `0` не скрывается.
- Адаптер не импортирует CSS; оформленный компонент использует CSS Module, токены и `@layer dreadnought` без `!important`.
- Не добавлять `BadgeCore`, форматирование счётчика, скрытие нуля, анимацию или новые зависимости.
- Не включать в коммиты уже существующее пользовательское удаление `packages/core/src/behaviors/.keep`.

## Review Focus

1. `children={0}` должен отображать `0`, а не исчезать из-за проверки на truthy; тест в Task 1.
2. Интерактивный `target` должен сохранить обработчик и фокус; тест в Task 1.
3. Порядок иконки `end` должен отличаться от `start`; тест в Task 1.
4. `className`, произвольный `data-*` и `ref` должны попадать на корневой `<span>` в обоих режимах; тест в Task 1.
5. Оформленная метка в обоих режимах должна получать вариант `outline` и не менять семантику адаптера; тест в Task 2.

- [ ] **Step 3: Implement the minimal structure.** Export `BadgeAdapter` from `DataDisplay/Badge/index.ts`, `src/unstyled.ts` and `src/index.ts`. The relevant render shape is:

```tsx
const content = <>
  {iconPosition === 'start' && icon != null && <span data-slot="icon" aria-hidden="true">{icon}</span>}
  <span data-slot="label">{children}</span>
  {iconPosition === 'end' && icon != null && <span data-slot="icon" aria-hidden="true">{icon}</span>}

</span>;
```

The prop type is `Omit<ComponentPropsWithRef<'span'>, 'children'> & { children: ReactNode; target?: ReactElement; icon?: ReactNode; iconPosition?: 'start' | 'end' }`. Destructure `ref` from props for React 19, preserve the rest on root, and use `iconPosition = 'start'`.
