# CodeBlock: дизайн компонента

Статус: предложенный контракт; реализация не начата.

## Задача и границы

`CodeBlock` показывает фрагмент исходного кода на лендинге и в документации. В первой версии он сохраняет пробелы и переносы строк, прокручивает длинные строки горизонтально и предоставляет встроенное копирование, которое можно отключить. Подсветку синтаксиса, номера строк, выделение диапазонов и выполнение кода откладываем. `language` сейчас служит только видимой подписью и заделом для будущей подсветки.

## Публичный контракт

```tsx
<CodeBlock code="import { Button } from '@dreadnought/ui/react';" language="tsx" />
<CodeBlock code="npm install ..." copyable={false} />
```

- `code: string` обязателен; пустая строка допустима. Код передаётся текстом, а не HTML, и React его экранирует.
- `language?: string` отображается обычным текстом в верхней панели. Не меняет содержимое `<code>` и не включает подсветку.
- `copyable?: boolean` по умолчанию `true`. При `false` кнопка копирования отсутствует. Если нет ни языка, ни кнопки, верхняя панель не рендерится.
- `copyLabels?: { copy: string; copied: string; error: string }` позволяет локализовать состояния кнопки; стандартные значения — `Copy`, `Copied`, `Copy failed`.
- `onCopy?: (code: string) => void` вызывается после успешной записи в буфер; `onCopyError?: (error: unknown) => void` — при ошибке. Ошибка не оставляется как необработанное отклонение промиса.
- `className`, `style`, стандартные свойства и `ref` относятся к корневому `<div>`. `slotClassNames?: { header?: string; pre?: string; code?: string; copyButton?: string }` даёт стабильные точки оформления значимых вложенных частей без привязки к случайной DOM-структуре.

## Поведение и доступность

Адаптер рендерит `<pre><code>{code}</code></pre>` и, если нужно, панель с языком и `ButtonAdapter type="button"`. Кнопка доступна с клавиатуры, не отправляет окружающую форму и имеет текстовое имя из `copyLabels`. Во время записи повторное нажатие блокируется. После успеха кнопка показывает `Copied`, после отказа — `Copy failed`; статус остаётся до изменения `code` или следующей попытки, без таймера. Изменение `code` сбрасывает статус; завершение старой операции после смены кода не обновляет новое состояние. Вызывающий код может обработать успех или ошибку через колбэки.

Кнопка не помещается внутрь `<pre>`, поэтому её текст не попадает в копируемый фрагмент. Отсутствие Clipboard API рассматривается как ошибка копирования и отражается тем же состоянием. Копируется ровно исходная строка `code`, включая конечные переводы строк.

## Ответственность слоёв

1. `core/actions.copy(text)` уже выполняет единственное самостоятельное действие. Новое action и пустой `CodeBlockCore` не создаём: дополнительных независимых правил первого слоя пока нет.
2. `adapters/react/src/DataDisplay/CodeBlock/` содержит неоформленный `CodeBlockAdapter`: разметку, вызов `copy(code)`, состояние операции, события и доступные имена. Он не импортирует тему или CSS. Самостоятельное использование адаптера остаётся возможным.
3. `ui/src/presentation/DataDisplay/CodeBlock/` содержит CSS Module и карту классов, `ui/src/adapters/react/components/DataDisplay/CodeBlock/` — готовый фасад. Он только добавляет классы; поведение копирования не повторяет. `themes/default` задаёт глобальные и компонентные токены, типографику и стандартное оформление.

Публичные входы: `CodeBlockAdapter` из `@dreadnought/react/unstyled`, `CodeBlock` из `@dreadnought/ui/react`, `copy` из `@dreadnought/core`. Внутренние исходные пути не становятся публичными.

## Проверка

- Адаптер сохраняет код без преобразований, пробелы и переносы строк; пустой код и отсутствие языка допустимы.
- Копирование передаёт в `copy()` точную строку, показывает состояния ожидания/успеха/ошибки и вызывает соответствующий колбэк; `copyable={false}` не обращается к Clipboard API.
- `ref`, нативные атрибуты и классы слотов попадают на оговорённые элементы; кнопка не отправляет форму.
- Готовый компонент подключает стили и тему, адаптер остаётся неоформленным. Значимые значения CSS приходят из токенов, без `!important` и произвольных чисел.
- Компонент представлен в Storybook и документации; сборка, типы и тесты workspace проходят.
