# Архитектура стилей Dreadnought

Статус: проект решения для согласования. Область: оформление компонентов библиотеки, начиная с Button.

## Цель и ограничения

Перенести из `C:/Users/vladi/Desktop/gg/job/14-monorepo` принцип разделения: общие значения в CSS, шрифтовые стили в отдельных классах, оформление каждого компонента в CSS Module. При этом сохранить три слоя Dreadnought и возможность применять разные дизайн-системы без изменения поведения компонента.

Правила:

- `core` и React-адаптер не импортируют стили. `ButtonAdapter` остаётся неоформленным.
- Все правила компоновки, внешнего вида, вариантов и визуальных состояний готового компонента находятся в его `*.module.css` в `packages/ui`.
- CSS-переменные и шрифтовые классы — оговорённые глобальные исключения. Других глобальных стилей компонента нет.
- Библиотека не устанавливает reset, стили `body`, `h1`, `button` и других элементов приложения.

## Размещение

```text
packages/ui/src/Button/
  Button.tsx
  Button.module.css        # Локальные классы кнопки, вариантов и слотов

packages/themes/src/default/
  colors.css               # Базовые цвета и семантические цветовые значения
  constants.css            # Расстояния, радиусы, размеры, параметры шрифтов и движения
  button.tokens.css        # Значения --dreadnought-button-* через общие переменные
  typography.css           # Глобальные .dreadnought-text-* классы
  index.css                # Публичный импорт темы
```

`fonts.css` с `@font-face` добавляется только при поставке самих файлов шрифтов. Тема не ссылается на абсолютные пути вида `/fonts/...`; семейства с системными запасными вариантами задаются в `constants.css`.

## Применение к Button

Готовый `Button` соединяет стабильный шрифтовой класс `.dreadnought-text-button`, локальные классы из `Button.module.css` и переданный пользователем `className`. `ButtonAdapter` не получает эти классы. Для веток `<button>` и `<a>` применяется один набор локальных классов; `loading` и `disabled` оформляются по уже существующим атрибутам состояния.

Шрифтовой класс задаёт `font-family`, `font-size`, `font-weight`, `line-height` и при необходимости `letter-spacing`. `Button.module.css` не дублирует эти объявления: он задаёт компоновку и размеры, фон, границу, цвет, интерактивные состояния и анимацию. Имена классов CSS Module являются внутренней деталью, а `data-ui` и `data-slot` сохраняются как документированные признаки DOM.

Токены существуют непосредственно в CSS, без обязательного JSON-источника: базовое значение → семантическое значение → токен компонента. Все публичные переменные имеют префикс `--dreadnought-`. Например, `--dreadnought-button-bg` может ссылаться на `--dreadnought-color-action-primary`.

## Смена дизайн-системы

`@dreadnought/themes/default.css` подключает стандартные значения и типографические классы. Проект может переопределить переменные на контейнере: вложенные `Button` получают другую тему за счёт наследования CSS-переменных; на одной странице могут быть разные темы. Шрифтовые классы остаются теми же, но читают значения темы.

Публичный путь изменения готового `Button` — документированные токены. Хешированные имена CSS Modules не являются API для переопределения. Если нужная геометрия или оформление не выражается токенами, проект использует `ButtonAdapter` и собственный CSS Module. `className` допускает локальную композицию, но не обещает заменить все правила стандартного модуля.

При интеграции с Figma агент предлагает изменения CSS-файлов темы проекта; исходники `core`, адаптера и поставляемой темы не переписываются. Для случая, требующего иной структуры или невыразимого токенами стиля, агент выбирает слой 2 или 1 и сообщает об этом.

## Сборка и проверки

Текущий `tsc` не переносит CSS Module в `dist`. Сборка `@dreadnought/ui` должна выпускать JS, декларации типов и стили вместе с корректным сопоставлением локальных классов. Импорт готового компонента подключает его локальные стили; стандартная тема подключается явно. `logic` и `unstyled` не должны приводить к импорту CSS.

Проверить Button в стандартной и локально переопределённой теме, неоформленный `ButtonAdapter`, состояния кнопки и ссылки, а также установку собранных пакетов во внешнее приложение. Проверка новой темы включает контраст, фокус и уменьшение движения.
