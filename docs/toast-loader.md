# Toast и Loader

Оба компонента находятся в семействе Feedback. Первый слой не зависит от React и DOM; второй связывает контракт с React; третий добавляет общие CSS Modules и токены темы.

## Toast

Toast сообщает о результате операции вне потока страницы. Alert остаётся постоянным сообщением внутри страницы.

- `getToastState` вычисляет видимость и роль `status` для info/success, `alert` для warning/error.
- `getCountdownRemaining` — общее чистое поведение для вычисления оставшегося времени. Часы и таймер остаются в адаптере.
- `useToast` управляет локальной или controlled-видимостью и отсчётом. Наведение и фокус приостанавливают его; продолжение использует оставшееся время.
- `ToastAdapter` задаёт доступную разметку, действие и закрытие. `ToastViewportAdapter` группирует уведомления без оформления.
- `Toast` и `ToastViewport` — готовые компоненты. Один viewport монтируется в корне приложения; элементы добавляет и удаляет владелец списка. Глобального singleton, провайдера и привязки первого слоя к React нет.

`duration` измеряется в миллисекундах, по умолчанию 3000. Значение 0 отключает автоматическое закрытие. Допустимы конечные неотрицательные значения до 2147483647. Повторное открытие либо изменение duration начинает новый отсчёт. В controlled-режиме callback запрашивает закрытие, а владелец меняет open. Escape работает только внутри уведомления при closable; уведомление не захватывает фокус. Для действия, которое нельзя пропустить, используйте duration=0.

Viewport поддерживает top-start, top, top-end, bottom-start, bottom, bottom-end; start/end учитывают направление текста. Длинная стопка прокручивается внутри viewport, не расширяя страницу. Fixed-контейнер размещайте вне предков с transform; пользовательский portal допустим, но не обязателен.

## Loader

`getLoaderState` вычисляет busy и семантику индикатора. `LoaderAdapter` сохраняет вложенное содержимое смонтированным, но делает его inert во время загрузки. `Loader` оформляет стандартное кольцо либо показывает пользовательский indicator без принудительного вращения.

Без children Loader — отдельный индикатор; с children он накрывает содержимое. loading=false снимает блокировку и скрывает индикатор. label задаёт доступное имя; showLabel выводит его визуально. Размеры — small, default, large. При reduced motion вращение отключено.

Loader показывает неопределённое ожидание, не процент выполнения. Полноэкранный прелоадер — сценарий размещения Loader, а не отдельный компонент. Переиспользование Loader в Button — отдельная миграция: текущий spinner Button здесь не меняется.
