# Документация Dreadnought — интерфейсный паттерн

- Аудитория: разработчик, который выбирает между готовым компонентом, адаптером и логикой. Страница должна ощущаться как спокойный технический справочник, а не промо-лендинг.
- Иерархия: постоянная навигация слева; в содержимом сначала название и назначение, затем живой пример, код трёх слоёв и API. Активный маршрут выделяется поверхностью, а не дополнительным акцентным цветом.
- Оформление: стандартная тёмная тема Dreadnought. Фон — `color-surface-canvas`, демонстрации — `color-surface-default`, текст и границы — существующие семантические токены. Глубину задают поверхности и тонкие границы без теней и градиентов.
- Типографика и ритм: использовать роли заголовков, body, label и caption из темы. Малые промежутки внутри примера берутся из `spacing-x2`, крупные промежутки между разделами — из `spacing-x4` и его кратных.
- Паттерн страницы компонента: пример строится из настоящего компонента библиотеки; код показан библиотечным `CodeBlock`; API — библиотечным `Table`. Общая структура не дублируется для каждого маршрута. На узком экране боковая панель сворачивается, а длинный код и таблица прокручиваются внутри своих областей.
